# 商家 HTML 报告设计

## 目标与范围

2026-10-13：重新设计六模块报告的导出 HTML。保留章节顺序、分析原文、平台口径、词云计数和证据。桌面工作台、模型调用、积分、Word 导出不在本次视觉修改范围内。

原版的过大标题、粗重分隔线和密集证据列表妨碍阅读；缺少完整视觉 brief 时，所有商家又会统一回退到灰底红线。新页面使用紧凑封面、章节侧栏、可比较的指标和按需展开的证据。

## 参考与设计取舍

- [Stripe 年度报告](https://stripe.com/annual-updates/2025)：参考标题、摘要和留白的层级，不复用其图片、品牌字体或页面代码。
- [Carbon 数据可视化](https://www.carbondesignsystem.com/building-blocks/data-visualization/overview)：参考明确标签、统一量纲和数据表达。这里保留原生 HTML/CSS 输出，不声称采用 Carbon 组件。

页面结构采用长报告与章节侧栏；页尾保留原报告说明。中文与数字分别使用本机字体栈，避免为离线报告引入外部字体和远程请求。设计 token 保持在 TypeScript 中，由现有导出器内联到文件。

## 商家风格

`htmlReportDesign.ts` 根据完整有效的视觉 brief，或 M1 中明确的产品身份字段选择风格。后者不修改事实可信度，也不读取竞品、评论、配方或购买偏好来猜品类。多品类冲突或信息不足时回退通用样式。

| 产品信息 | 视觉方向 | 结构差别 |
| --- | --- | --- |
| 食品、饮料 | 自然绿、暖白、柔和圆角 | 使用场景和核心人群突出 |
| 美妆、珠宝 | 克制玫瑰色、宋体展示字 | 精简封面、产品规格横排 |
| 家居、家纺 | 亚麻纸色、木色 | 较舒展的产品信息与生活场景 |
| 数码、设备 | 冷白、蓝色、等宽数字 | 紧凑边框、明确参数分组 |
| 健康相关产品 | 温和青色 | 清楚的信息分组与证据层级 |
| 玩具、运动等 | 暖色重点、较活泼字重 | 更显著的产品标题和柔和分组 |
| 企业与工业 | 灰蓝、紧凑直角 | 参数与决策依据优先 |
| 信息不足 | 中性蓝灰 | 不猜测品牌定位 |

品牌名称（缺失时用产品名称）决定稳定的封面变体。同一品牌多次导出不会随机换皮。自动选择的是报告设计配色，不代表已取得商家的官方品牌色；商家名称取自原报告。

## 词云与证据

- 保持原始 Top20、素材出现次数、覆盖率、Top1/2/3 与辅助得分。
- 云图区呈现权重，旁边的前六项条形排行用于准确比较次数。
- 使用原生单选控件与 CSS `:has()` 切换证据，无脚本、网络或模型请求。
- 焦点位于词语自身，方向键可切换，选择不跳到页面顶部；较旧 CSS 引擎回退显示全部证据。
- 屏幕按需查看证据，打印保留所有来源副本。长词在云图区可省略显示，但可通过完整标签和证据标题查看全文。

## 验证

四个带明确“合成测试数据”标记的商家样例，在 320 / 375 / 414 / 768 / 1440 像素下检验导航、词语边界、证据切换和键盘操作；保留旧报告的 2560 像素与打印验证。对主要文字和背景计算 WCAG 对比度。导出 CSP 保持 `script-src 'none'`、`connect-src 'none'`。

真实已完成项目离线重新渲染，逐段比较六个完整报告副本及二十项词云统计，要求完全一致。`scripts/render-saved-report.cjs` 只读取项目与经过哈希验证的 blob，拒绝覆盖已有文件，不读取授权、不调用模型。

设计复核：Philosophy 5 / Hierarchy 4 / Execution 4 / Specificity 4 / Restraint 4 / Variety 4。保留本机中文字体和数据图表分组是离线报告的实现约束；不宣称营销页面通用审美清单的全部条目都适用于数据报告。
