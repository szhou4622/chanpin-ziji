# 产品经营报告：小白用户发版测试清单

## 发版通过标准

- 全程不能白屏、闪退、卡死，也不能把半截内容当作完整报告。
- 用户点错、断网或关闭软件后，已经上传的资料和上一份完整报告不能丢。
- 所有失败提示必须说明“发生了什么、内容是否保留、下一步点哪里”。
- 同一个按钮连续点击，最多只执行一次。
- 首次使用者不看教程，也能完成激活、设置、上传、生成、确认和 Word 导出。

## A. 安装、启动和激活

- [ ] 1. 全新安装后，桌面图标、开始菜单图标和窗口图标都显示产品原图。
- [ ] 2. 连续双击桌面图标 10 次，只出现一个软件窗口。
- [ ] 3. 1366×768、125% 缩放时，激活按钮和关键说明完整可见。
- [ ] 4. 150% 和 200% 缩放时，页面可操作，不出现点不到的按钮。
- [ ] 5. 激活码为空时提交，显示中文提示，不闪退。
- [ ] 6. 激活码小写、前后空格、复制多一个换行时，可自动整理后正常校验。
- [ ] 7. 错误激活码不会被保存为已激活，也不会破坏原授权。
- [ ] 8. 激活成功后立刻强制关闭，再打开仍保持已激活。
- [ ] 9. 激活主记录损坏但备份正常时，软件自动恢复授权。
- [ ] 10. 激活写盘遇到磁盘满或无权限时，不显示“成功”。

## B. 第一次模型设置

- [ ] 11. 第一次进入时，“先去设置模型”点击后设置页一定出现在最上层。
- [ ] 12. 未配置模型时，隐私确认的继续按钮不可误点。
- [ ] 13. API Key 为空不能保存，并明确提示先粘贴 Key。
- [ ] 14. API Key 前后空格和换行会自动清理。
- [ ] 15. 第一次配置必须“测试连通”成功后才能保存。
- [ ] 16. 测试失败时步骤不能显示已完成。
- [ ] 17. 测试成功后修改 Key、地址或模型名，成功标记立即失效。
- [ ] 18. 修改设置后误按 Esc 或关闭，软件提示是否放弃修改。
- [ ] 19. 选中新模型后保存，实际分析使用的就是刚选中的模型。
- [ ] 20. 普通远程 HTTP 地址被拒绝；HTTPS 和本机 localhost 地址按规则可用。
- [ ] 21. 模型地址返回网页、非法 JSON、空内容时，不能显示“连通成功”。
- [ ] 22. 读图测试选择非图片、超过 10MB 图片时，直接友好拒绝。
- [ ] 23. 更换模型服务地址后，重新显示对应地址的隐私确认。

## C. 上传和资料识别

- [ ] 24. 单独上传 PNG、JPG、CSV、XLSX、PDF、DOCX、PPTX、TXT、Markdown、ZIP 均能完成处理。
- [ ] 25. 旧版 DOC、PPT 明确提示格式限制，不假装解析成功。
- [ ] 26. 空文件、损坏文件、改错扩展名文件不会参与分析。
- [ ] 27. 密码 PDF、扫描 PDF、损坏 PDF 给出可执行的中文提示。
- [ ] 28. UTF-8、GBK/GB18030、UTF-16LE、UTF-16BE 文本和 CSV 中文不乱码。
- [ ] 29. CSV 含逗号、引号、单元格换行时列内容保持正确。
- [ ] 30. 未闭合引号等无法安全判断的 CSV 显示解析失败，不当作正常数据。
- [ ] 30A. 只有少数行多列、少列或尾部多逗号时，静默整理并显示绿色“可分析”，保留所有非空内容继续分析。
- [ ] 30B. 7 份以上资料进入 AI 清洗时最多同时处理 4 份，不再固定为 2 份。
- [ ] 31. 单文件超过 40MB 时立即拒绝，不长时间卡住。
- [ ] 32. 图片超过 25MB 或像素异常大时拒绝或缩放，不占满内存。
- [ ] 33. 201 个文件只接收 200 个，并只显示一条数量说明。
- [ ] 34. 已有一批文件解析中时，再拖入一批不会并行叠加。
- [ ] 35. 正常文件和失败文件混合上传，处理进度最终显示 100%。
- [ ] 36. 未明确识别归属的资料显示“待确认”，开始按钮说明还差几份。
- [ ] 37. ZIP 中不同目录的同名文件能显示完整目录，不互相覆盖。
- [ ] 38. 空 ZIP、损坏 ZIP、嵌套 ZIP、密码 ZIP、高压缩比 ZIP 都不会卡死。
- [ ] 39. ZIP 内超大图片也会经过尺寸检查和压缩。
- [ ] 40. 文件解析中删除、关闭软件或新建分析，不会让旧结果晚到污染新分析。

## D. 生成、停止和断网

- [ ] 41. 没有可用资料时不能开始生成。
- [ ] 42. 文件仍在解析时，按钮显示“正在读取资料”，不能反复点击。
- [ ] 43. 开始前输入分析目标，发送后明确显示“已保存”，并进入后续分析。
- [ ] 44. 中文输入法按 Enter 选词时不会误发送。
- [ ] 45. 资料整理完成后停在第一次确认，正式分析结束后停在初稿确认。
- [ ] 46. 清洗中断网，自动重试后仍失败时返回可重试状态，资料保留。
- [ ] 47. HTTP 401、404、429、500、502、503、504 都显示容易理解的处理建议。
- [ ] 48. 服务一直不响应，最多等待限定时间后自动停止，不永久转圈。
- [ ] 49. 模型只返回一半并以 length/content_filter 结束，不能提交为完整结果。
- [ ] 50. 流式回复没有结束标记就断开，保留上一份完整报告。
- [ ] 51. 模型返回空内容、非法 JSON、网页或超长内容，不能进入“完成”。
- [ ] 52. 清洗、分析、成稿不同阶段点击停止，都显示“已停止”而不是“软件错误”。
- [ ] 53. 点击停止后马上新建，旧模型回复晚到也不能写进新分析。
- [ ] 54. 成稿期间补充新要求，初稿完成后会自动按新要求再修订。
- [ ] 55. 中途失败后修改核心要求，旧分析步骤会作废并重新计算。

## E. 保存、新建、恢复和重启

- [ ] 56. 文件刚解析完成后立即关闭，重开资料仍存在。
- [ ] 57. 报告最后一段刚出现就立即关闭，重开仍是完整报告。
- [ ] 58. 修改资料归属或说明后立即关闭，重开修改仍存在。
- [ ] 59. 关闭保存失败时软件不直接退出，明确提示检查磁盘后再关。
- [ ] 60. 点击“新建分析”再取消，当前内容完全不变。
- [ ] 61. 确认新建后，资料、对话和报告变为空白，设置与激活不变。
- [ ] 62. 新建写盘失败时自动恢复当前内容，不留下半清空状态。
- [ ] 63. 新建成功后出现“恢复上一份”，点击可完整恢复资料和报告。
- [ ] 64. 归档上一份失败时不能继续清空当前分析。
- [ ] 65. 上次运行中途退出，重开显示“上次任务已中断”，不假装仍在运行。
- [ ] 66. 主项目文件为空对象、损坏或版本较旧时，自动选择有效的新备份。

## F. 定稿和导出

- [ ] 67. 初稿未确认时不能导出“最终 Word”。
- [ ] 68. 资料变化后，旧报告明确标注“上一版”，只能按备份导出。
- [ ] 69. 确认定稿前会校验预览内容与完整成稿一致。
- [ ] 70. 连续双击导出只出现一个保存窗口。
- [ ] 71. 取消保存不显示失败，也不生成空文件。
- [ ] 72. Word 文件被占用、目录无权限、磁盘满、U 盘拔出时，旧文件不被破坏。
- [ ] 73. 中文长路径和同名覆盖可正常导出，文件能被 Word 打开。
- [ ] 74. 报告预览顶部按原版依次显示“导出 HTML / 导出 MD / 导出 Word”三个并排按钮，不改成下拉菜单。

## G. 覆盖安装和最终发版

- [ ] 75. 从上一版覆盖安装后，激活、模型设置和上次报告全部保留。
- [ ] 76. 安装时软件仍在运行，安装器给出清楚提示，不损坏正在保存的项目。
- [ ] 77. 安装器、主程序、桌面快捷方式和卸载器图标一致。
- [ ] 78. 安装器和主程序版本号与交付文件名一致。
- [ ] 79. 安装包完成病毒扫描；如未做代码签名，发版说明必须明确 Windows 可能提示风险。
- [ ] 80. 在一台从未安装过本软件的 Windows 电脑上，完整走通一次真实业务报告。

## H. 坏文件隔离与小白快捷操作

- [ ] 81. 同时选择多个 CSV/PDF/XLSX/ZIP 时按顺序解析，界面按钮和窗口拖动始终有响应。
- [ ] 82. 某个损坏文件导致解析组件异常退出时，只提示该文件失败，下一份正常文件仍能继续处理。
- [ ] 83. 超复杂文件处理超时后自动停止，不残留后台解析进程，也不影响新建分析。
- [ ] 84. 动态 GIF、动态 WebP、APNG 明确提示截取静态画面，不进入浏览器完整解码。
- [ ] 85. 图片伪造小画布、超大真实帧、错误 RIFF 长度、截断头部时直接拒绝，不白屏或内存暴涨。
- [ ] 86. 点击“未确认项全部设为自有/竞品”前会显示数量确认，且不覆盖已经手动选择的资料。
- [ ] 87. 失败或忽略的文件在确认页显示“无需确认”，平台、类型和说明为空也不会阻止生成。
- [ ] 88. 导出成功后“打开刚导出的文件”和“打开所在文件夹”都能定位到本次结果。
- [ ] 89. 连续双击打开按钮只执行一次；文件被移动后提示重新导出并隐藏失效按钮。
- [ ] 90. 打包后检查 ASAR 中包含 `out/main/parse-utility.js`，并用安装版实际解析 CSV、PDF、XLSX、ZIP。

## 每次失败的记录格式

记录：测试编号、软件版本、Windows 版本、屏幕缩放、操作步骤、实际结果、期望结果、截图或录屏、是否丢资料、重启后能否恢复。
